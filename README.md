# Training 2026 — UI/UX Assignment

A dashboard recreated from the course demo using CSS Grid and vanilla JavaScript. The page supports English and Arabic, including a right-to-left layout in Arabic mode.

**Student** Hala Jaber 
**University ID** University ID: 202404820

## Features

- Responsive dashboard with a sidebar, two animation panels, and a scrollable lesson on HTML, CSS, and JavaScript.
- Animated CSS shapes and a rotating anatomical heart.
- Header and floating buttons for adding numbered updates, with controls for deleting individual updates or clearing the list.

## Project files

| File | Purpose |
| --- | --- |
| `index.html` | Contains all HTML, CSS, JavaScript, and embedded assets. |
| `Prompt.txt` | Contains the single AI prompt for recreating the dashboard from the course demo. |

## Run locally

Download or clone the repository and open `index.html` in your browser. The page works offline and requires no installation.
